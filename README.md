# battleship

**A classic game brought to life on the web, featuring interactive gameplay and a strategic cpu opponent.**

[Live Demo](https://emgrey02.github.io/battleship/)


## Overview

This project is a web-based implementation of the timeless strategy board game, Battleship. Players can engage in turn-based combat, strategically placing their ships and attempting to sink the opponent's fleet before their own is destroyed. The game features an interactive user interface and an intelligent cpu opponent to provide a challenging and engaging experience.

## Features

-   **Classic Battleship Gameplay**: Recreation of the original game rules and mechanics.
-   **Intelligent CPU Opponent**: Challenge yourself against a computer player with strategic targeting capabilities.
-   **Interactive Game Boards**: Visually clear grids for both player and CPU, displaying hits, misses, and sunken ships.
-   **Flexible Ship Placement**: Manually arrange your fleet or quickly randomize placement before battle.
-   **Turn-Based Combat**: Engage in an alternating attack sequence until one fleet is entirely sunk.
-   **Game State Management**: Robust system for tracking game progress, turns, and victory conditions.
-   **Responsive Design**: Enjoy the game seamlessly across various devices and screen sizes.
-   **Modern Development Workflow**: Built with Webpack, Babel, and Jest for a streamlined and maintainable codebase.
